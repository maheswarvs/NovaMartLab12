# NOVA MART – online shopping website (HTML, CSS, JavaScript, XML)
Run: open this folder in VS Code, install the "Live Server" extension, right-click index.html > Open with Live Server.
Any local server works, e.g. `python -m http.server 8000` then http://localhost:8000. Opening index.html by double-click will not
load the products, because browsers block reading data/products.xml from file:// pages.
Edit data/products.xml to add or change products. Replace images/product-N.svg with your own photos and update the <image> path in the XML.
Login/Register is a browser-only demonstration, not secure authentication.
